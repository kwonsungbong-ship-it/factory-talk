# 폰 꾸미기 (Deco Lock)

삼성 Good Lock 스타일의 폰 꾸미기 앱. 삼성 전용 API 없이 안드로이드 표준 기능(접근성 서비스, 알림 리스너, 오버레이, 런처, 라이브 배경화면, 위젯, 빠른 설정 타일)만 사용해 안드로이드 8 이상 모든 폰에서 동작한다.

| Good Lock 모듈 | 이 앱 |
|---|---|
| Edge Lighting+ | 엣지 라이팅 (효과 4종, 무지개/테마색/앱 아이콘 색) |
| One Hand Operation+ / Edge Touch / Edge panel | 엣지 핸들 제스처 4방향 + 엣지 패널(앱·도구) |
| NavStar | 떠 있는 내비게이션 바 |
| Home Up | 런처 (아이콘 모양·크기·격자, 독, 앱 서랍, 검색) |
| LockStar / ClockFace | 커스텀 잠금 화면 + 시계 6종 |
| Wonderland | 기울기 반응 라이브 배경화면 5장면 + 배경화면 생성기 |
| NotiStar / Nice Catch | 알림 기록 (30일, 검색, 지워진 알림 포함) |
| Sound Assistant | 볼륨 패널, 볼륨키=미디어 볼륨 |
| QuickStar | 빠른 설정 타일 5종 |
| Theme Park | 테마색, 시계 위젯 |

빌드: GitHub Actions(`.github/workflows/deco-lock.yml`)가 APK를 만들어 Releases에 `deco-v1.0.N` 태그로 올린다.
