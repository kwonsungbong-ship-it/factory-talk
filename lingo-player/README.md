# Lingo Player — 언어학습 음악 플레이어

기기에 저장된 음악/강의 오디오 파일을 재생하면서 **단어 단위로 가사처럼 싱크된 텍스트**를 보여주는 앱입니다.
Factory Talk와는 별개의 앱이며, 이 폴더 하나로 완결됩니다.

## 기능
- 음악 파일 추가(MP3/M4A/WAV 등) → 기기 안 IndexedDB에 저장. MP3는 길이 제한 없음(프레임 경계로 잘라 20MB씩 전송·조각 디코딩), 그 외 형식은 25MB(클라우드)/12MB(기기 내) 이하
- **분석**: Whisper API(단어 타임스탬프)로 문장·단어 타이밍 추출, 결과는 기기에 저장되어 한 번만 분석
  - 클라우드: **Groq**(기본, 무료 티어, `whisper-large-v3` + 채팅 `openai/gpt-oss-120b`, 판정 `qwen/qwen3.8-27b`, 모델이 사라지면 다음 후보로 자동 전환) 또는 **OpenAI**(유료, `whisper-1` + `gpt-4o-mini`)
  - **기기 내(오프라인)**: transformers.js + ONNX Whisper(`_timestamped` 모델, 단어 타임스탬프 지원)를 폰에서 직접 실행. WebGPU가 되면 GPU, 아니면 CPU(WASM). 모델은 최초 1회 다운로드 후 브라우저 캐시에 저장.
    - large-v3-turbo(최고 정확도, GPU 약 1.6GB / CPU 약 1.1GB), medium, small(약 250MB), base(약 80MB)
    - 번역·단어 뜻은 기기 내 모드에서도 클라우드 키가 있을 때만 동작 (없으면 가사 싱크만)
  - 단어 힌트: 교재 단어·이름을 넣으면 클라우드 인식 시 철자 보정(`prompt`)
  - **두 번째 언어(이중 언어 모드)**: 음성에 두 언어가 섞여 있으면(예: 베트남어 단어 + 한국어 뜻) Whisper는 한 요청을 한 언어로만 받아쓰고, 긴 파일을 통째로 보내면 둘째 30초 창부터 문맥에 끌려 양쪽 언어가 모두 망가집니다. 그래서 오디오를 16kHz로 풀어 무음(50ms RMS, 0.3초 이상)으로 **발화**를 나누고, 발화마다 그 구간만 WAV로 잘라 언어 자동 감지로 보냅니다. 짧은 단어도 혼자 들려주면 언어와 텍스트가 정확히 나옵니다. 감지 언어가 두 언어 밖이면(짧은 단어에서 가끔) 두 언어를 각각 강제해 조각의 `avg_logprob`가 높은 쪽을 택합니다(한 조각은 30초 창 하나라 이 값이 그 발화의 실제 신뢰도). 요청 수 = 발화 수. `whisper-large-v3`와 `whisper-large-v3-turbo`를 번갈아 써 무료 한도(모델당 분당 20회)를 두 배로 씁니다. 15분 어휘 파일(약 600발화)은 15분 안팎 걸립니다. 합성 이중 언어 음성 32발화로 검증: 2음절 이상 단어는 언어·텍스트 정확, 1음절 단어는 TTS 품질 한계로 일부 오류.
- 재생 중 현재 단어 노란색 하이라이트, 현재 문장 강조 + 자동 스크롤
- 문장 탭 → 그 문장부터 재생, 단어 탭 → 뜻/발음 팝업(캐시됨) 및 "여기부터 재생" (줄 번역 기능은 사용자 요청으로 제거)
- 이전/다음 문장, 5초 이동, 문장 반복, 재생 속도(0.5~1.25x), 글자 크기

## 잠금화면·백그라운드 재생
- 안드로이드 앱은 `@jofr/capacitor-media-session` 플러그인으로 재생 중 미디어 알림을 띄우고 포그라운드 서비스로 화면이 꺼져도 재생을 유지합니다.
- 잠금화면/알림에는 **현재 문장**이 제목으로, 그 번역이 아티스트 자리에 표시되며 문장이 바뀔 때마다 갱신됩니다.
- 컨트롤: 재생/일시정지, 이전·다음(= 이전·다음 문장), 탐색바, 이어폰 버튼. 웹/PWA에서는 브라우저의 Media Session API를 그대로 씁니다.

## API 키
설정(⚙)에서 제공자(Groq/OpenAI)를 고르고 그 서비스의 API 키를 입력합니다. 키는 기기(localStorage)에만 저장됩니다.
- 내장 키: GitHub 저장소 Settings → Secrets and variables → Actions 에 `GROQ_API_KEY`를 등록하면 빌드 시 APK에 내장되어 입력 없이 바로 씁니다. 설정에서 키를 입력하면 그 키가 우선합니다.
- 주의: 이 저장소는 공개이므로 릴리스 APK도 누구나 받을 수 있고, APK 안의 내장 키는 추출될 수 있습니다. 키를 소스 코드에 직접 쓰지 마세요.

## 서명 키 (업데이트 시 데이터 유지)
CI가 매번 새 디버그 키로 서명하면 새 APK를 기존 앱 위에 설치할 수 없어 삭제 후 재설치해야 하고, 저장된 곡·분석·설정(API 키 포함)이 사라집니다. GitHub Secret `SIGNING_KEYSTORE_B64`(PKCS12 키스토어의 base64, 비밀번호·키 비밀번호 `lingo-player`, 별칭 `lingo`)를 등록하면 항상 같은 키로 서명한 release APK를 만들어 업데이트가 제자리 설치되고 데이터가 유지됩니다. 키스토어 파일은 저장소에 넣지 않습니다(공개 저장소).
- Groq: console.groq.com 가입 → API Keys. 카드 없이 무료 (하루 약 28,800초 오디오, 분당 20요청, 25MB 제한). 분석·번역·단어 뜻 모두 Groq 키 하나로 동작.
- OpenAI: 선결제 필요. Whisper 분당 약 $0.006, 번역·단어 뜻은 gpt-4o-mini.

## 손상된 MP3
- 유튜브 변환 MP3에 손상 프레임이 있으면 안드로이드 웹뷰(Symphonia 디코더)는 재생을 중단합니다(`PIPELINE_ERROR_DECODE`). 이때 앱이 자동으로 조각 디코딩(손상 조각은 8프레임 묶음으로 재시도)해 22.05kHz 모노 WAV로 변환·저장하고 같은 위치부터 이어 재생합니다.

## 긴 파일 처리
- 클라우드: 24MB를 넘는 MP3는 프레임 경계에서 20MB 단위로 나눠 보내고, 각 조각의 시작 시각(프레임 수 기준)만큼 타임스탬프를 밀어 합칩니다.
- 기기 내: MP3를 1.5MB 단위로 조각 디코딩해 메모리 피크를 수십 MB로 유지합니다. 중간 조각은 디코더 지연(1105 + 1프레임 샘플)만큼 앞을 잘라 재생 타임라인과 맞춥니다(클릭 신호로 ±1샘플 검증, 44.1k/48k).
- 분석이 끝나면 워커를 종료해 모델 메모리를 해제합니다.

## 파일
- `index.html` 앱 본체, `stt-worker.js` 기기 내 Whisper 워커(모듈 워커, CDN에서 transformers.js 로드)

## 빌드
- 웹/PWA: 이 폴더를 HTTPS로 서빙하면 바로 동작 (`python3 -m http.server`로 로컬 테스트 가능)
- Android APK: `.github/workflows/lingo-player.yml` — `lingo-player/` 변경을 main에 푸시하거나 수동 실행하면 `LingoPlayer.apk`가 Release(`lingo-v1.0.N`)에 올라갑니다.

## 주의
- 유튜브에서 오디오를 받는 기능은 앱에 넣지 않았습니다(유튜브 약관/스토어 정책). 파일은 사용자가 직접 준비해 추가합니다.
- 반주가 큰 노래는 인식률이 떨어질 수 있습니다. 보컬이 또렷한 학습용 음원에 가장 잘 맞습니다.
